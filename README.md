# 🛒 EasyMart

A modern and responsive **full-stack e-commerce platform** built with **React** that enables users to browse products, manage their cart, place orders, and enjoy a seamless online shopping experience.

## 🌐 Live Demo

🔗 **Demo:** https://easy-mart-mx5z.vercel.app/

## ✨ Features

* 🔐 User Authentication (Login & Signup)
* 🛍️ Browse and search products
* 🛒 Add, update, and remove items from cart
* ❤️ Wishlist management
* 📦 Order tracking and order history
* 👤 User profile and settings page
* 📱 Fully responsive design
* 📞 Contact and support page
* 🎨 Modern and intuitive user interface

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/easymart.git
```

### 2. Navigate to the project directory

```bash
cd easymart
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

Open http://localhost:5173 in your browser to view the application.
